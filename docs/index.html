Market Screener

A free Google Sheets screener for US and India stocks, commodities, and crypto. It runs on Google's servers every morning and emails you the signals.

Download ZIP View on GitHub

What it does

  • Watchlists in a Google Sheet. One tab each for US Stocks, India Stocks, Commodities (gold, silver, oil), and Crypto. Add or remove assets by editing rows. Untick a checkbox to pause one.
  • Signals. Breaches and crosses of the 20, 50, and 200-day averages, golden and death crosses, Darvas box breakouts, RSI extremes, and volume spikes.
  • Results in the same sheet. A Results tab with every asset, an Alerts tab with only the flagged ones, and a Log tab for errors.
  • Daily email digest at 7am IST, after the Indian close and the previous US close.

Get started

1. Download the code

Either download the ZIP and unzip it, or clone the repo:

git clone https://github.com/rahuling/market-screener.git

You only need Code.gs and appsscript.json. The rest of the repo is documentation.

2. Create the Apps Script project

  1. Go to script.google.com and click New project.
  2. Replace the contents of Code.gs with the file from the repo.
  3. Open Project Settings (gear icon), tick Show "appsscript.json" manifest file in editor, then go back to the editor. Replace the contents of appsscript.json with the file from the repo.
  4. Save with Ctrl+S (Cmd+S on a Mac) and rename the project to Market Screener.

3. Run it once

  1. In the function dropdown at the top, choose runScreener and click Run.
  2. Approve the permissions when asked. Google will show an "unverified app" warning because the script is your own. Click Advanced, then continue.
  3. The run creates a spreadsheet called Market Screener in your Drive, with the four watchlist tabs, and emails you a digest.

4. Schedule the daily run

Choose setupDailyTrigger from the dropdown and click Run once. It schedules runScreener every day at 7am.

5. Edit your watchlist

Open the spreadsheet and edit the input tabs:

  • Add: type a symbol and name in a new row, then tick Enabled.
  • Pause: untick Enabled.
  • Remove: delete the row.

Notes

  • Yahoo Finance and CoinGecko are free and unofficial. They can change or rate-limit requests. Check the Log tab if a run has errors.
  • Crypto uses daily closes only, so the Darvas box for crypto is approximate.
  • Assets need at least 201 days of history to compute the 200-day average. Newer listings are skipped and logged.
  • This is a screening tool for research and learning, not investment advice.
